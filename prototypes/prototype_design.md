# Final Grade Calculator — Prototype Design

**Group:** 4  
**Designer:** Jakedrian Wright

## 1. Main Screen

The main screen will allow students to enter their course information and grades.

**Elements:**
- Application title: Final Grade Calculator
- Input field for course name
- Input fields for assignment, quiz, and exam grades
- Input field for the final exam grade
- Button labeled "Calculate Grade"
- Button labeled "Reset"

## 2. Results Screen

The results screen will display the calculated grade.

**Elements:**
- Current numerical course grade
- Estimated letter grade
- Input for desired final course grade
- Calculated final exam score needed to reach the desired grade
- Button labeled "Calculate Required Score"
- Button labeled "Back to Main Screen"

## 3. User Workflow

1. The student opens the application.
2. The student enters grades and course information.
3. The student clicks "Calculate Grade."
4. The application displays the estimated course grade.
5. The student can enter a desired final grade to calculate the final exam score needed.

## 4. Design Goals

- Keep the interface simple and easy to understand.
- Clearly label all input fields and buttons.
- Display results in a readable format.
- Validate inputs and explain errors to the user.
